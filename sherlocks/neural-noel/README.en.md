# Neural Noel — Hack The Box (Sherlock)

**English** | [🇪🇸 Español](README.md)

> **State:** Retired. Methodology note; no literal answers or real data.

## Scenario

Santa's automated support uses a chatbot. HTTP logs, suspicious files and prompts are provided; determine whether someone manipulated the assistant or exfiltrated data.

## Evidence

- Access and application logs from the AI service.
- Files uploaded or generated by the chatbot.
- No model or API key.

```bash
grep -iE 'prompt|chat|completion|upload' access.log
```

## Investigation

### 1. Inventory and triage

Separate normal requests from those containing instructions, files or URLs. Chat, upload and internal tool endpoints matter most.

### 2. Timeline

Sort by time and user. Look for prompt-injection sequences: instructions to ignore rules, reveal the system prompt or call a tool.

```text
User -> malicious prompt -> response -> internal request -> exfiltration
```

### 3. Key artefact

The prompt and response show whether the model obeyed untrusted input. The resulting file or destination URL confirms impact.

## Conclusions

- The chatbot processed untrusted input.
- Prompt injection may have revealed instructions or data.
- Logs identify user, session and destination.
- Design must separate system instructions from user data.

## Lessons

- LLMs do not inherently separate instructions from content.
- Validate model tools and outputs.
- Application logs matter as much as network logs.
